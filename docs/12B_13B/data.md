# 12B / 13B 数据说明

修订日期：2026-08-25

本文记录 12B/13B 类载荷标定数据的来源、文件对照关系和各个文件的特殊情况
（哪些文件有坑、坑是什么）。072 / 073 / 074 是同批三台探测器的数据目录，
**072 = GRID-12B**，073 / 074 为另外两台（其一为 13B，具体对应待确认）；
三台是不同设备，数据不能互相对照或混用。

数据处理方法（HK 怎么截取、峰怎么找、拟合怎么配）见 [../data.md](../data.md)，
本文不重复。

## EC 数据（X 光机与放射源，072）

EC（能量-道址）标定数据在 `X光机/072/` 和 `放射源/072/`。

### X 光机数据

文件命名 `{序号}_{管压kV}_ch{通道}.dat/.hk`；dat 与 hk 的序号不一致，按
（管压, 通道）配对；同点有重测时取序号最大者。各管压点位的状态：

| 管压 | 状态 | 说明 |
|------|------|------|
| 15 kV | 未入 EC | 只有噪声台附近的包络峰，ch3 双峰无法分离；整点放弃，拟合数据留在 `EC_fit_result/15.pickle` |
| 20-45 kV | 仅供参考 | 包络峰可见、可拟合，但位置对"能量=管压"有系统偏差（阈值截断 + 堆积，见下） |
| 47/49 kV | 弃用 | 部分通道的 hk 文件截断：只有升压段几条记录（偏压最高 12-20V），没有 28.5V 平台段，无法做温偏修正。全部 74 个 X 光 hk 的 CRC 校验均 100% 通过，是采集不完整而非数据损坏 |
| 51/53 kV | 不参与拟合 | 按 B 方案惯例落入 Gd K 边拆分的 49-55 keV 死区 |
| 55/60/65 kV | 仅供参考 | 同 20-45 kV 的偏差问题，程度较轻（~5%） |
| 70/80/100 kV | **正式锚点** | 峰位与"能量=管压"自洽（100 kV 峰位 532 vs E-C 预测 534） |
| 75 kV | 弃用 | ch1 缺 hk，通道不全 |
| 90 kV | 弃用 | 只有 `_old` 后缀的 hk |
| 110 kV | 弃用 | 072 只有 ch0 一个文件 |

低管压点位的物理问题：管压越低，连续谱端点离探测器阈值越近
（40 kV 端点 ≈160 ADC，噪声沿 ~110 ADC），谱形被阈值截断；同时端点以上
仍有计数尾巴（40 kV 数据的计数延伸到 ~700 ADC，约合 130 keV 表观能量，
真实光子不可能超过管压，只可能是两个光子的堆积）。这类峰包的拟合位置
不代表管压对应的能量，不能当 EC 锚点。

### 放射源数据

`0611` 系列（2026-06-11 采集）：Na22（511 keV）、Cs137（662 keV）、
Co60（1173 + 1332 keV 双峰）、Am241（59.5 keV），`0611env` 是共用的
环境本底。各轮的标称偏压都是 28.5V、温度 31-40°C。特殊情况：

- **Am241 曾被误判弃用**：它的 hk 开头带升压段，对全记录取平均得到
  20.4V（低于击穿电压），据此曾判断"科学数据无信号"。实际 604 条 hk
  记录里 422 条在 28.0-28.5V 平台（众数时段即平台期），科学数据全程有
  信号，59.5 keV 峰拟合良好（2026-08-25 复查后入库）。
- **Co60 的两个全能峰相距仅 ~3σ**：左峰（~6450 ADC）是 1173 keV，右峰
  （~7440 ADC）是 1332 keV，最初曾把左峰错当 1332，导致 662 keV 残差
  恒为 +2.3%。判峰方法：双峰位置比应等于能量比（1173/1332 = 0.88），
  并用 Na22 的 1275 keV 峰（未参与拟合）做独立验证。最终用双高斯拟合
  （窗口覆盖两峰，`bkg_form="gaus"`），1332 残差收敛到 +0.1~0.3%。

## 温度偏压（TB）数据：电压档位与文件对应表

`/home/wqd/cali_data/12B、13B/` 下有三份表格和一套日志/数据文件，共同描述
温度偏压实验的点位安排。本文把它们整理成可查的对照关系。

- `data/温度偏压/电压数据点.xlsx`：偏压档位表（电压 ↔ DAC 十六进制码）。
- `数据文件对照表.xlsx`：每台设备每个（温度, 偏压）点位对应的 hk 文件编号和
  observe 数据文件编号。sheet 名 072 / 073 / 074 是三台设备，其中
  **072 = GRID-12B**（已确认）；073 / 074 为同批另外两台设备（其一为 13B，
  具体对应待确认）。
- `data/备份/{dev}/`：原始文件。`hk/ecu_1_{NNN}.hk` 是工程参数（hk）文件，
  `sample/{NNN}_observe.dat` 是科学数据文件，`log/ecu_1_{NNN}.txt/.png`
  是对应编号的运行日志和 hk 曲线图。对照表里的 "hk" / "observe" 两列就是
  这三处共用的编号 NNN。
- `高低温循环/时间表.xlsx`：另一个实验（−25°C ↔ 50°C 高低温循环 5 次）的
  温箱程式，与温度偏压标定无关，不在本文范围内。

## 与已整理数据的关系及其他说明

- `data/温度偏压/072/TB_*.dat/.hk` 是 12B 负温度档位（0/−10/−20/−30°C）的
  整理版，内容与备份对应（已用 md5 验证，如 `TB_m30C_290.dat` ==
  `备份/072/sample/030_observe.dat`）。正温度档位（10/20/30°C）没有整理版，
  只能用上表从 `备份/072/sample/` 取 observe 文件——如果后续要把 TB 覆盖
  扩展到正温度，按此表取数即可。
- 表中有若干编号乱序的点位（如 072 的 0°C/287 → 154/76、−20°C/290 → 68/20），
  是补测/重测造成的，取数以表为准。
- 已发现的坏文件（处理时剔除）：`TB_m10C_270.dat`、`TB_m10C_287.dat` 分别是
  265/283 点位的逐字节复制（原始数据丢失）；对照表中这两个点位的备份编号为
  −10°C/270 → 93/33（前半段）、−10°C/287 → 158/78，如需恢复可从备份取。

## 备份完整性核对（2026-08-24）

- 备份 hk 文件时间跨度比整理版长：除升压爬升段外，还可能带点位结束后的
  回温段（`ecu_1_088.hk` 在同一 29V 下从 −16.4°C 回温到 +29.5°C），取平台
  必须按（偏压, 温度）二维稳定段截取，只卡偏压会被回温段污染。
- 放射源和 X 光机 hk 开头同样带升压段（0611 系列都从低偏压爬到 28.5V），
  对 hk 全记录取平均会得到错误偏压（Am241 轮曾因此被误判，见上文 EC 部分）。

对 `备份/072` 按上表逐项核对的结果：

- **56 个点位引用的 112 个文件路径全部存在且非空**（55 个 hk + 55 个 observe，
  −10°C 的 270/275 两点共用 093/033），无缺失。
- 备份里另有 113 个 hk、29 个 observe 文件未被表引用（预热、爬压、ivscan、
  补测等过程文件），其中 `sample/057_observe.dat` 和 `hk/ecu_1_071.hk`
  是 0 字节空文件，但都不在表内，不影响标定点位。
- 抽查正温度点位的可用性：30°C/290（074_observe + ecu_1_151.hk）偏压平台
  29.00V、SiPM 温度 45.4°C，Am241 峰清晰可辨（ch0 峰位 ~290、prominence
  7.2；ch3 ~346、prominence 8.9），峰位随温度升高下移的趋势与负温度数据
  一致，正温度扩展可行。
