# N1（GRIDN1）数据说明

修订日期：2026-08-26

本文记录 GRIDN1 载荷标定数据的来源、文件组织和各个文件的特殊情况。
GRIDN1 是中子/伽马双探测器载荷（GAGG 晶体通道测伽马、CLYC 晶体通道测中子），
与 GRID B 系列同族但包格式和数据组织不同。数据处理的方法论见
[../data.md](../data.md)；本载荷的早期处理流水线在另一个仓库
`gridN_cali`（分层 L0/L1/L2 + Snakemake），本仓库的 N1 接入复用了它的
包定义 XML 和人工拟合区间，但直接从原始二进制文件处理，不依赖它的中间产物。

## 数据来源与组织

原始数据在 `/home/wqd/cali_data/GRIDN1/data/`（软链为 `data/N1/raw_data`）。
温度偏压实验在 `260303温度偏压/` 下，按数据集分两个目录：

- `GAGG/`：**Am241 源**（59.5 keV）的测量，结果只针对 GAGG 晶体通道
  ch1/ch2。负温度（m20C/m10C）是每个偏压
  一个文件（`m20C-265-125.event.dat` = −20°C 档、26.5V），非负温度
  （0C/10C/20C/30C）是**偏压扫描文件**（`0C-265-290-139.event.dat`，一个文件
  依次测 8 个偏压点）。
- `CLYC/`：**Na22 源**（511 keV）的测量，四个通道全部参与拟合。
  全部 6 个温度都是偏压扫描文件，且部分扫描末尾有补测偏压段
  （如 m20C 扫描多 277/279/281 三个回测点）。

要排除的文件：名字带 `To` 的是温度转换段、`CI` 是电流扫描、`test` 是
测试轮，都不是 TB 点位。`260302温度偏压测试/` 是更早的一轮，未使用。

## 数据格式（与 12B 的关键差别）

- GAGG 文件是 584 字节的 `grid1x_ft_packet`（38 事件/包、每事件 14 字节，
  比 12B 多一个 data_ccm 字段）；CLYC 文件是 1080 字节的 `grid1x_wf_packet`
  （512 点波形包，用 `grid_packet_512wave.xml`，分块解析并滤掉 CRC 错误的
  事件）——两种包的 data_max/data_base/data_sum 字段都在，幅度都按
  `amp = data_max − data_base/4` 计算
- hk 文件是 178 字节的 `hk_packet`（定义在 `yingtian_packet.xml`；与 12B 的
  187 字节 `grid1x_hk_packet` 头魔数相同但字段布局不同）
- **N1 的科学包带真实 utc**（12B 地面数据 utc 全 0），所以科学数据与 hk 按
  最近 utc 对齐，扫描文件按"utc 间隔大于 4 秒的安全间隙"切成偏压段
  （与 gridN_cali 的 L0 notebook 同一逻辑），用 `seg_bias` 参数按实测偏压
  选段（容差 0.1V）
- 包定义 XML 复制自 `gridN_cali/reader/`（`grid_packet.xml`、
  `grid_packet_512wave.xml`、`yingtian_packet.xml`），解析引擎与
  reader11/12 相同

## 两个数据集不能在同一个 ADC 尺度上拟合

两轮用的是不同的放射源（GAGG 轮 Am241 59.5 keV，CLYC 轮 Na22 511 keV），
同一个通道在两轮里拟合的是不同能量的峰，峰位 ADC 差约 9-10 倍（如 ch1 在
−20°C/29V：Am241 峰 ~500 ADC，Na22 峰 ~4950 ADC，比值接近能量比
511/59.5 ≈ 8.6）。TB 二维面拟合的是"峰位随 (温度, 偏压) 的相对变化"，
不同能量的峰不能放进同一个面。因此 N1 的 TB 拟合按数据集分头进行：
ch1/ch2 在 GAGG 数据上拟合，ch0/ch3 在 CLYC 数据上拟合，最后按通道归并成
标准的单文件输出 `temp_bias_fit.json`（4 元素数组按通道索引，与其他载荷
相同；归并规则见 `TB_operation_N1.CHANNEL_DS`）。同时保留两份按源的完整
记录：`temp_bias_fit_am241.json`（GAGG 轮，ch1/2）和
`temp_bias_fit_na22_511.json`（CLYC 轮，四通道全部，含 ch1/2 的 Na22 面，
可用于与 Am241 面交叉验证相对响应形状）。

Na22 的 1274 keV 峰评估过、放弃：这批数据的采集幅度在 ~8700 ADC 处截断
（各通道均有溢出尖峰），1274 峰位（511 峰 ×2.494）在 28.3V 以上全部越界；
ch0/ch3 谱被噪声主导也看不到 1274 峰。只有 ch1/ch2 的 ≤28.0V 段可见，
覆盖太弱，不足以拟合温偏面。

## 拟合区间来源与坏点

`fit_range.json` 从 `gridN_cali/data/TB_{GAGG,CLYC}/L1_cfg/*_fit_cfg.yaml`
转换而来（它们的人工区间，含 `can_fit: false` 的通道置 null），覆盖了全部
107 个点位（96 个标准偏压 + 11 个 CLYC 补测段）。

已知的坏点（两套处理里都一样坏，是数据本身的问题）：

- **CLYC m20C 扫描的 265/270/275 段的 ch0/ch3**：CLYC 低增益通道在最低偏压
  下峰无法区分（gridN 自己的拟合在这几段同样错乱，ch0 峰位非单调），
  已在 `fit_range.json` 置 null
- GAGG 轮（Am241）只针对 ch1/ch2，ch0/ch3 区间本来就多为 null，
  二维拟合也只做 ch1/ch2
